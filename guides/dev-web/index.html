💻 Développement Web

Apprendre à créer des sites et applications web modernes.

Introduction

Le développement web regroupe toutes les compétences nécessaires pour créer un site ou une application accessible sur internet. C'est un domaine accessible aux débutants, avec une courbe d'apprentissage progressive : on peut créer sa première page en quelques heures, puis approfondir année après année. Ce guide te présente les fondations essentielles pour bien démarrer.

Les bases à connaître

🏗️ HTML & CSS

HTML (HyperText Markup Language) et CSS (Cascading Style Sheets) forment les fondations de toute page web : le premier structure le contenu, le second définit son apparence visuelle.

HTML décrit les éléments d'une page à l'aide de balises : un titre (`<h1>`), un paragraphe (`<p>`), une image (`<img>`), un lien (`<a>`). Sans CSS, une page HTML s'affiche avec une mise en forme brute, sans couleurs ni mise en page élaborée.

CSS permet de définir les couleurs, les espacements, les polices, la disposition des éléments (grâce à des techniques comme Flexbox ou Grid), et les animations. C'est ce qui transforme une structure brute en interface soignée.

💡 À retenir : HTML répond à la question "quel contenu ?", CSS répond à la question "à quoi ça ressemble ?" — les deux sont indissociables pour créer une page web complète.

⚡ JavaScript

JavaScript est le langage qui rend une page web interactive : il permet de réagir aux actions de l'utilisateur (clics, saisie de texte) et de modifier dynamiquement le contenu d'une page sans avoir à la recharger entièrement.

Exemples d'usages courants : afficher/masquer un menu au clic, valider un formulaire avant envoi, charger de nouvelles données sans recharger la page (comme sur les réseaux sociaux), ou créer des animations interactives.

Le DOM (Document Object Model) est la représentation de la page HTML que JavaScript peut lire et modifier. C'est grâce au DOM que JavaScript peut, par exemple, changer le texte d'un bouton ou ajouter une nouvelle image sur la page en réponse à une action utilisateur.

💡 À retenir : sans JavaScript, un site reste statique (comme une page de brochure). Avec JavaScript, il devient une véritable application interactive.

🔗 Frontend vs Backend

Un site web complet repose généralement sur deux parties distinctes qui communiquent entre elles : le frontend et le backend.

Le frontend ("côté client") regroupe tout ce que l'utilisateur voit et manipule directement dans son navigateur : la mise en page, les couleurs, les interactions. Il est construit avec HTML, CSS et JavaScript (souvent via des frameworks comme React ou Vue).

Le backend ("côté serveur") gère la logique invisible : stockage des données (bases de données), authentification des utilisateurs, traitement des paiements, ou envoi d'emails. Il tourne sur un serveur distant, pas dans le navigateur de l'utilisateur.

Exemple concret : sur un site e-commerce, le frontend affiche joliment les produits et le panier ; le backend vérifie le stock disponible, calcule le prix final, et enregistre la commande en base de données.

💡 À retenir : un développeur "frontend" se concentre sur l'interface visible, un développeur "backend" sur la logique serveur — un développeur "fullstack" maîtrise les deux.

📱 Responsive Design

Le responsive design consiste à concevoir un site pour qu'il s'affiche correctement sur tous types d'écrans : ordinateur, tablette, smartphone — chacun ayant des tailles et proportions différentes.

Les media queries CSS permettent d'appliquer des styles différents selon la largeur de l'écran. Par exemple, une navigation qui s'affiche horizontalement sur ordinateur peut s'empiler verticalement sur mobile pour rester lisible et utilisable.

L'approche "mobile-first" consiste à concevoir d'abord la version mobile d'un site, puis à l'adapter progressivement pour des écrans plus larges — plutôt que l'inverse. Cette approche est de plus en plus recommandée, la majorité du trafic web mondial provenant désormais des smartphones.

💡 À retenir : un site non responsive perd une grande partie de ses visiteurs potentiels — tester systématiquement l'affichage mobile est aujourd'hui indispensable, pas optionnel.
