Introduction

Le développement web regroupe toutes les compétences nécessaires pour créer un site ou une application accessible sur internet. C'est un domaine accessible aux débutants, avec une courbe d'apprentissage progressive. Ce guide te présente les fondations essentielles pour bien démarrer.

Les bases à connaître

🏗️ HTML & CSS

HTML et CSS forment les fondations de toute page web : le premier structure le contenu, le second définit son apparence visuelle.

HTML décrit les éléments d'une page à l'aide de balises (titre, paragraphe, image, lien).

CSS permet de définir couleurs, espacements, polices, disposition (Flexbox, Grid) et animations.

💡 À retenir : HTML répond à "quel contenu ?", CSS répond à "à quoi ça ressemble ?"

⚡ JavaScript

JavaScript rend une page web interactive : il réagit aux actions de l'utilisateur et modifie dynamiquement le contenu.

Exemples d'usages : afficher/masquer un menu, valider un formulaire, charger des données sans recharger la page.

Le DOM est la représentation de la page HTML que JavaScript peut lire et modifier.

💡 À retenir : sans JavaScript, un site reste statique.

🔗 Frontend vs Backend

Un site complet repose sur deux parties : le frontend (ce que voit l'utilisateur) et le backend (la logique côté serveur).

Le frontend est construit avec HTML, CSS, JavaScript, souvent via des frameworks comme React ou Vue.

Le backend gère le stockage des données, l'authentification, les paiements.

💡 À retenir : un développeur fullstack maîtrise les deux.

📱 Responsive Design

Le responsive design consiste à concevoir un site pour qu'il s'affiche correctement sur tous types d'écrans.

Les media queries CSS permettent d'appliquer des styles différents selon la largeur de l'écran.

L'approche mobile-first consiste à concevoir d'abord la version mobile, puis à l'adapter pour des écrans plus larges.

💡 À retenir : tester systématiquement l'affichage mobile est aujourd'hui indispensable.
